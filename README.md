# YAStudio

Project tracker for a video editing agency. Kanban pipeline from client submission through admin QA, client review, revisions, and approval.

## Stack

Next.js (App Router) + TypeScript + Tailwind v4 + `lucide-react`. No backend — mock data seeded into `localStorage`.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
